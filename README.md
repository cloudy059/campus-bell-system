# 校园音乐铃声播放系统

基于 Electron 的校园自动音乐铃声播放系统：按作息时间表自动播放铃声音乐，支持多套作息方案、音乐库管理、考试播报、语音合成与播放日志，开箱即用。

## ✨ 功能特性

### 自动打铃
- **秒级调度引擎**：按作息时间表自动播放，当日防重复触发，5 秒宽限窗防止系统卡顿漏打
- **多套作息方案**：按星期几自动匹配生效（如"标准作息"周一~五、"周末方案"），每条铃声可独立设置时间、名称、关联音乐与启用开关
- **特殊日期调整**：支持**单日或日期范围**（含首尾两天）、**自定义名称**（如"期中考试周"）；**整块「特殊日期」容器可一键收起 / 展开**（标题栏点击，状态随设置保存、重启保持），内部每条记录也可单独折叠或一键全部收起；设为"假期"（不打铃）或"改用指定方案"。同一天有多条时单日记录优先；法定节假日模板按节日导入为带名称的范围卡片
- **提前播放**：每条铃声可配置提前秒数（如预备铃提前 60 秒）
- **临时静音**：30 分钟 / 到今日结束，可随时取消
- **多曲连播**：单条铃声可关联随机 / 顺序多曲连播，支持总限时自动停止

### 音乐库
- 导入本地音频：mp3 / wav / m4a / aac / ogg / flac / opus（自动拷贝到媒体目录统一管理）
- **在线音乐**（网易云音乐，下载入库后本地播放，界面参考 SPlayer 的信息组织方式）：
  - **发现音乐**：四个分段板块 —— 推荐歌单卡片网格（封面 / 播放量 / 歌曲数）、排行榜（官方榜 / 精选榜，卡面直接显示前 3 首与更新文案，可展开全部）、新歌速递（全部 / 华语 / 欧美 / 韩国 / 日本）、个性推荐
  - **搜索**：云搜索结果含封面、专辑、别名、VIP 标签、时长；热搜词一键搜索；支持「加载更多结果」分页
  - **挑选与下载**：歌曲列表可多选 / 全选、双击试听、单曲或批量下载（实时进度与失败明细）；下载音质可选标准 / 较高 / 极高 / 无损，无对应音质时使用最高可用音质
  - **歌单 / 榜单详情**：封面、创建者、歌曲数、播放量、简介与标签；点击卡片直接载入曲目
  - 所有在线请求自动重试一次，避免偶发 DNS 抖动导致板块空白；失败时显示可重试入口
  - **取链风控自愈**：网易 `player/url/v1` 对单 IP 有突发频率限制，快速连点试听或批量下载会返回 `-460 检测到您的网络环境存在风险`。取链会自动降级到旧版播放接口与两个下载接口（播放接口优先，保证 VIP 歌曲仍有约 30 秒试听片段），并对请求做串行限速、CDN 链接缓存 5 分钟、v1 触发风控后熔断 5 分钟；只有全部备用接口都失败时，才在页面常驻提示等待 / 登录 / 换网络。已下载到本地的铃声不受任何影响
- **网易云账号登录**：扫码 / 短信验证码 / Cookie 三种方式；登录后 VIP 歌曲可下载完整版，凭证仅保存在本机 `netease.json`，不参与备份导出
  - 短信登录受网易风控影响较大：失败时界面会常驻显示网易返回的真实原因与错误码（如 405 发送过频、503 验证码错误、400 风控拦截），发送按钮带 60 秒倒计时；被拦截或反复失败时请改用**扫码登录**（默认，推荐）或 Cookie 登录
- **内置合成铃声**：首次运行纯代码合成 5 首 WAV（上课铃、下课铃、预备铃、放学铃、西敏寺钟声），**无需自备音频文件**
- 试听播放、重命名、分类（预备 / 上课 / 下课 / 课间操 / 午休 / 放学 / 仪式 / 其他）、搜索过滤
- 音频片段截取：从现有曲目截取片段保存为新铃声

### 考试播报
- **内置 2026 年高考示例**：首次运行自动生成 8 场考试（6 月 7–9 日，新高考「3+1+2」常见日程）与一套"标准播报流程"方案；可在考试页点「载入高考示例」重新导入（只补齐缺失项，不覆盖已有数据），并可勾选同时添加高考期间的特殊日期范围来暂停常规铃声
- 考试安排管理：日期、科目、开始时间、时长、启用开关与倒计时状态
- 多套可复用播报节点方案（考试通过方案 ID 引用），节点触发时机支持开考前 / 开始考试 / 结束前 / 考试结束
- **语音合成 TTS**：Edge TTS 在线语音（多种播音人、语速、音调）+ Windows SAPI 本地语音兜底

### 播放器与界面
- 底部常驻播放条：播放 / 暂停 / 停止、进度拖动、主音量、淡入淡出可配置
- 输出设备选择（setSinkId）
- 仪表盘：大屏渐变时钟、下次铃声倒计时、今日铃声时间线（已播放 / 即将响铃 / 已过未播 / 静音跳过）
- 播放记录：自动 / 手动 / 静音跳过三类日志，上限 2000 条，可一键清空
- 深色 / 亮色主题切换，现代深色设计

### 系统集成
- **运行时阻止电脑休眠**：防止休眠导致铃声漏播（可在设置中关闭；开启期间屏幕不会自动熄灭）
- 关闭窗口最小化到系统托盘，后台继续按时打铃；顶部迷你悬浮条快捷控制
- 开机自启、单实例锁、托盘气泡告警（播放失败等）
- 数据一键备份 / 恢复（方案、曲库、设置、日志、全部音频）

## 🚀 快速开始

### 环境要求

- [Node.js](https://nodejs.org/) ≥ 18（建议 20+）
- Windows 10 / 11

### 运行

```bash
# 安装依赖（国内可加镜像加速 Electron 下载）
npm install --electron_mirror=https://npmmirror.com/mirrors/electron/

# 启动应用
npm start
```

首次运行会自动生成 5 首内置铃声、默认作息方案，以及一套「2026 年高考」示例考试与播报方案，开箱即用。示例日期仅作演示，请按本校考试院通知修改。

### 打包安装包

```bash
npm run pack
```

输出 NSIS 安装包至 `dist2/` 目录。

## 📁 数据存储

所有用户数据保存在 `%APPDATA%\校园音乐铃声系统\`：

| 文件 / 目录 | 说明 |
|---|---|
| `library.json` | 音乐库索引 |
| `schedules.json` | 作息方案与特殊日期 |
| `exams.json` / `exam-schemes.json` | 考试安排与播报节点方案 |
| `settings.json` | 应用设置 |
| `netease.json` | 网易云登录凭证（Cookie，仅本机保存，**不参与备份导出**） |
| `logs.json` | 播放日志（上限 2000 条） |
| `media\` | 音频文件目录 |

应用内"设置 → 打开目录"可直达；支持一键备份与恢复。

## 🛠️ 技术架构

| 层 | 实现 |
|---|---|
| 主进程 `main.js` | 无边框窗口 + 自定义标题栏、系统托盘常驻、单实例锁、防休眠（`powerSaveBlocker` 的 `prevent-display-sleep` + 禁用后台定时器节流）、IPC 数据持久化、Edge TTS / SAPI 语音合成 |
| `preload.js` | contextBridge 安全暴露 `window.bellApi`（contextIsolation） |
| 渲染进程 | 原生 HTML / CSS / JS 单页应用（6 个页面），无框架无打包 |
| 音频 | HTML5 Audio：淡入淡出、主音量、输出设备选择、进度拖动 |
| 在线音乐 | NeteaseCloudMusicApi 4.32（`cloudsearch` / `toplist_detail` / `top_song` / `personalized` / `playlist`；取链 `song_url_v1` 自动降级到 `song_url` / `song_download_url_v1` / `song_download_url`，带缓存与限流；扫码、短信验证码、Cookie 三种登录方式，所有请求统一携带登录凭证；播放始终走本地文件） |

## 🗓 版本历史

### v1.2.0（2026-11-08）
- **特殊日期升级**：支持**日期范围**（含首尾）与**自定义名称**；**整块特殊日期容器可一键收起 / 展开**（状态存 `settings.json`，重启保持），单条记录也可折叠 / 全部收起；主界面与迷你悬浮条均按范围匹配，同一天有多条时单日记录优先，完全兼容旧的单日数据；节假日模板改为按节日导入带名称的范围卡片并自动合并旧单日记录。
- **内置 2026 高考示例**：首次运行写入 8 场考试 + 一套 6 节点标准播报方案，考试页提供「载入高考示例」入口（可重复导入、不覆盖已有数据，可附带高考期间的特殊日期范围）。

### v1.1.0
- **修复防休眠失效**：改用 `prevent-display-sleep` 真正产生系统级电源请求；禁用 Chromium 后台定时器节流，避免隐藏到托盘后漏打铃；设置页开关改为显示主进程真实状态。
- **新增网易云账号登录**：扫码 / 短信验证码 / Cookie 三种方式，登录后 VIP 歌曲可下载完整版；凭证仅保存在本机，不参与备份导出。
- **在线音乐重构**：参考 SPlayer 的信息组织方式，新增推荐歌单 / 排行榜 / 新歌速递 / 个性推荐四个板块、热搜词、云搜索分页、多选批量下载、音质选择与更完整的歌曲列表。
- **取链风控自愈**：网易 `-460 网络环境存在风险` 时自动降级到备用接口，配合链接缓存与请求限流，VIP 歌曲仍可试听；风控提示改为页面常驻引导。
- 短信登录失败时显示网易返回的真实错误码与原因，不再笼统提示「登录失败」。

### v1.0.0
首个版本：自动打铃、作息方案、音乐库、考试播报、语音合成与播放日志。
